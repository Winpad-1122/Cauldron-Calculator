# 煉藥鍋顏色計算器

一個用於自動計算並渲染《Minecraft》中儲水煉藥鍋染料混合結果的輔助工具。

## 功能

- **混合預覽**：選擇染料後即時顯示煉藥鍋中的顏色變化。
- **版本支援**：支援 BE1、BE3、BE4、BE5、BE6、BE7。（其中 BE5 與 BE7 相同；由於無論任何水位都無法在 BE2 中顯示，該程式省略 BE2）
- **水位支援**：支援水量為 Level 2-6。（Level 0-1 在該視角下不可視，故該程式對其省略）
- **智慧序列計算**：輸入目標顏色，程式自動計算最優染料序列。（遺傳演算法）
- **批量渲染**：一次性渲染指定長度範圍內的所有有效的染料序列，序列的有效性判定遵循 zh.minecraft.wiki 論壇最新的有關染色煉藥鍋渲染圖命名的提案 Diff/1457167 及其修正案 Diff/1457170 與 Diff/1457173。
- **圖片匯出**：將目前煉藥鍋狀態匯出為 PNG 圖片。圖片的命名規則遵循 zh.minecraft.wiki 論壇最新的有關染色煉藥鍋渲染圖命名的提案 Diff/1457167 及其修正案 Diff/1457170 與 Diff/1457173。
- **多語言支援**：簡體中文、繁體中文、英語、日本語。

## 使用說明

### 手動渲染

1. 選擇遊戲版本（BE1、BE3、BE4、BE5、BE6、BE7）
2. 選擇填充層數（Level 2-6）
3. 點擊染料按鈕加入到序列中
4. 即時觀察煉藥鍋顏色變化
5. 可匯出目前狀態為圖片

### 批量渲染

在「批量渲染」對話框中設定：
- 序列長度範圍
- 目標版本
- 目標層數

程式會自動生成所有有效的組合並匯出為圖片。

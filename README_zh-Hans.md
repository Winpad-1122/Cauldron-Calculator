# 炼药锅颜色计算器

一个用于自动计算并渲染《Minecraft》中储水炼药锅染料混合结果的辅助工具。

## 功能

- **混合预览**：选择染料后实时显示炼药锅中的颜色变化。
- **版本支持**：支持 BE1、BE3、BE4、BE5、BE6、BE7。（其中BE5和BE7相同；由于无论任何水位都无法在BE2中显示，该程序省略BE2）
- **水位支持**：支持水量为 Level 2-6。（Level 0-1在该视角下不可视，故该程序对其省略）
- **智能序列计算**：输入目标颜色，程序自动计算最优染料序列。（遗传算法）
- **批量渲染**：一次性渲染指定长度范围内的所有有效的染料序列，序列的有效性判定遵循zh.minecraft.wiki论坛最新的有关染色炼药锅渲染图命名的提案Diff/1457167及其修正案Diff/1457170与Diff/1457173。
- **图片导出**：将当前炼药锅状态导出为 PNG 图片。图片的命名规则遵循zh.minecraft.wiki论坛最新的有关染色炼药锅渲染图命名的提案Diff/1457167及其修正案Diff/1457170与Diff/1457173。
- **多语言支持**：简体中文、繁体中文、英语、日本语。

## 使用说明

### 手动渲染

1. 选择游戏版本（BE1、BE3、BE4、BE5、BE6、BE7）
2. 选择填充层数（Level 2-6）
3. 点击染料按钮添加到序列中
4. 实时观察炼药锅颜色变化
5. 可导出当前状态为图片

### 批量渲染

在“批量渲染”对话框中设置：
- 序列长度范围
- 目标版本
- 目标层数

程序会自动生成所有有效的组合并导出为图片。

# 大釜色計算機

Minecraft における水入り大釜の染料混合結果を自動計算・レンダリングする補助ツールです。

## 機能

- **混合プレビュー**：染料を選択すると大釜の色変化が即座に表示されます。
- **バージョン対応**：BE1、BE3、BE4、BE5、BE6、BE7 をサポート。（BE5 と BE7 は同一です。BE2 はどの水位でも表示できないため省略されています。）
- **水位対応**：水位 Level 2-6 をサポート。（Level 0-1 はこの視点では不可視のため省略されています。）
- **インテリジェントシーケンス計算**：目標色を入力すると、最適な染料シーケンスを自動計算します。（遺伝的アルゴリズム）
- **バッチレンダリング**：指定した長さ範囲内の有効な染料シーケンスをすべて一括レンダリングします。シーケンスの有効性判定は zh.minecraft.wiki フォーラムにおける染色大釜レンダー命名に関する最新提案 Diff/1457167 および修正案 Diff/1457170、Diff/1457173 に準拠します。
- **画像エクスポート**：現在の大釜状態を PNG 画像としてエクスポートします。命名規則は zh.minecraft.wiki フォーラムにおける染色大釜レンダー命名に関する最新提案 Diff/1457167 および修正案 Diff/1457170、Diff/1457173 に準拠します。
- **多言語対応**：簡体字中国語、繁体字中国語、英語、日本語。

## 使い方

### 手動レンダリング

1. ゲームバージョンを選択（BE1、BE3、BE4、BE5、BE6、BE7）
2. 水位を選択（Level 2-6）
3. 染料ボタンをクリックしてシーケンスに追加
4. 大釜の色変化をリアルタイムで観察
5. 現在の状態を画像としてエクスポート可能

### バッチレンダリング

「バッチレンダリング」ダイアログで設定：
- シーケンス長の範囲
- 対象バージョン
- 対象水位

プログラムが自動的にすべての有効な組み合わせを生成し、画像としてエクスポートします。
